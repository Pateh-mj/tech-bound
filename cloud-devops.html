01 / WHAT THIS FIELD IS

Cloud & DevOps in plain terms

So you know what you are walking into — and what you are not.

What people in this field actually do
  • Ship software repeatedly with less manual risk
  • Provision and manage infrastructure as code
  • Watch systems in production and respond when they degrade
  • Containerise and orchestrate services when it helps
  • Balance speed of delivery with reliability and cost
Common entry paths
  • Cloud engineering — AWS, GCP, Azure building blocks
  • SRE / reliability — SLOs, incidents, recovery
  • CI/CD — pipelines that test and deploy safely
  • Platform engineering — internal developer platforms
  • FinOps-aware ops — performance with cost awareness
Mindset that matters

If you cannot deploy it twice, you do not own it yet. Observability is not optional. Prefer reversible changes. Automate the boring path so humans handle the exceptions.
